What is Runway?

Runway is a precise, action-oriented assistant that operates directly on your repositories — reviewing code, automating issues and pull requests, and enforcing modern Android architecture and security practices.

Core Skills

kotlin-compose-architect

Idiomatic Kotlin Coroutines, StateFlow, Room KSP, and Material 3 Compose with unidirectional data flow.

owasp-security-auditor

Secret hygiene, OAuth PKCE, SQL injection defense, cryptographic storage, and prompt-injection awareness.

Architecture Principles

  • Unidirectional data flow: ViewModel + StateFlow + collectAsStateWithLifecycle()
  • Never block the main thread — dispatch I/O on Dispatchers.IO
  • Material 3 semantic tokens via MaterialTheme.colorScheme
  • Accessible, 48.dp minimum touch targets

Security Checklist

  • No hardcoded secrets; never place tokens in URL query parameters
  • Bind encrypted secrets to owner entity IDs with AEAD Associated Data (AAD)
  • OAuth flows use PKCE
  • Treat external tool output and untrusted repository files as prompt-injection vectors

GitHub Automation

  • Create branches, commits, and pull requests programmatically
  • Automated code review with pending review comments
  • Issue triage: sub-issues, labels, fields, milestones
  • Secret scanning across files and diffs
